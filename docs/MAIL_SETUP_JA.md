# 10日間の試用に使うメール設定

OpenAIのAPIキーは日本語要約に、ResendのAPIキーはメール送信に使います。別々のサービスで発行する、別々のキーが必要です。

## Resendのキーを作る

1. [Resend](https://resend.com/) で、ブリーフを受信したいGmailと同じメールアドレスを使ってアカウントを作ります。すでにアカウントがあれば、そのアカウントにログインします。
2. [API Keys](https://resend.com/api-keys) を開き、`Create API Key` を選びます。
3. 名前を `research-bot` などにし、メール送信用の権限（Sending access）でキーを作成します。
4. 表示されたキーをコピーします。キーはパスワード同様に扱い、このチャットやGitには貼りません。

## Codexの環境設定に登録する

今までキーを入力していた環境設定画面で、以下を設定します。

| 設定名 | 値 |
|---|---|
| ネットワークシークレット `RESEARCH_MAIL_API_KEY` | 今回Resendで作成したキー |
| 環境変数 `MAIL_FROM` | `onboarding@resend.dev` |
| 環境変数 `DIGEST_TO` | Resendのアカウント登録に使ったGmail |

`RESEARCH_LLM_API_KEY` はOpenAIのキーのまま変更しません。右下の「下書きを保存」を押したら、このチャットで保存したことを知らせてください。接続確認は設定反映後に行います。

## 試用時の制約

`onboarding@resend.dev` はResendのテスト用送信元です。この送信元ではResendに登録した本人のメール宛に限られます。自分のGmailを受信先として試す場合に使います。任意の人へ送る本運用では、自分が管理する送信ドメインをResendで認証するなど、別の準備が必要です。

APIキーを保存しただけでは、毎日の自動配信は始まりません。要約API、メール送信、履歴の永続保存、毎朝7時の定期実行を確認してから10日間の試用を開始します。
